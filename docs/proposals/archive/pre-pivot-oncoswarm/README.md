# OncoSwarm Pre-Pivot Project Archive

This directory contains archival documentation from the team's original B.Tech capstone problem statement: an LLM-based multi-agent oncology tumor-board simulation system ("OncoSwarm").

The project direction was deliberately abandoned in August 2026 after landscape research (see `problem_statement_landscape_report.md` in this directory) revealed that the target niche had already been saturated by a published, deployed Stanford tumor-board system. Following this discovery, the team executed an intentional and documented research pivot to autonomous multi-agent pharmacovigilance signal triage (PharmaGuard).
